# ROBUST-TAMP: author details for the project page

The ROBUST-TAMP project page (https://narendhiranv04.github.io/ROBUST-TAMP/) is published from an anonymous branch,
so the same page can also be mirrored for double-blind review. On github.io the page loads `authors.json` from this
repository (same origin, `/ROBUST-TAMP-authors/authors.json`) and shows the authors, affiliations, logos, BibTeX
authors and the code link. Anywhere else the file is not found and the page stays anonymous.

Edit `authors.json` to change what the public page shows; the page itself does not need to change.
